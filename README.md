# SGP-Cron
Tareas programadas del Sistema de Gestión de Personal

## Tareas programadas en el proyecto

- Registro de ausencias.
- Reporte de ausencias.
- Notificación de ausencias a `SGP-Movil`.
- Registro automático de asistencia en días no laborables, tanto oficiales como no oficiales.
- Registro automático de asistencia en los días de descanso establecidos individualmente para cada empleado.
